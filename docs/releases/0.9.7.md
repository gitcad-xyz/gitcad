# 0.9.7 — the capability release

Six packages: `gitcad`, `gitcad-core`, `gitcad-mech`, `gitcad-ecad`,
`forgekernel`, `forgekernel_rs`.

0.9.6 shipped no new capability; this release ships twelve cells. The matrix is
327/345 in 0.9.6 and **339/345 (98%)** here: 1 honest refusal remains
(chamfered box × fillet(all)), 5 cells are marked outside any exact field
permanently, 0 crashes. The enabling change is one function: the canonical
B-rep's coordinate coercion `F()` now admits ℚ[√d] and ℚ[√d][π], so solids
whose faces meet at irrational heights can enter the canonical form at all. A
float is still converted to its exact binary Fraction, never admitted as
itself — widening the domain is not dropping the check.

Several answers that were wrong are also now right, and two of those change
shipped geometry. Read the breaking section first.

## Breaking: geometry output changed

* **Shelling a union whose members touch was a silent wrong number.** The green
  `disjoint union (boss) × shell` cell shelled each member separately, but
  members that touch are one connected solid: the exposed rim where the boss
  meets the plate erodes to a quarter torus swept inside the plate, which the
  member-wise answer cannot see. The probe moves from 1916 + 60π (2104.4956)
  to the composite erosion 1916 + (103/3)π + 2π² (2043.6006) — the old answer
  was 60.9 mm³ heavy. Touching unions outside the recognized bossed-plate
  pattern now refuse by name instead of returning a pile wearing a number.
* **Two gapped coaxial bores grew a phantom shoulder (W6).** `from_drilled`'s
  shoulder loop walked adjacent bands with only an equal-radius skip, so two
  blind bores separated by a slab of material acquired a phantom annulus
  hanging inside the solid — mass off by an exact π multiple (4800 − 34π
  where the true answer is 4800 − 39π on the two-blind-bore plate) while
  `validate().ok` stayed True. The shoulder is now skipped when bands do not
  touch, the drilled-cut path runs through the answer audit (it was the one
  constructive path still skipping it), and the closed form is pinned golden.
* **`fillet(all)` on a non-box prism returned a box's answer.** The box
  predicate accepted any prism whose vertices are a subset of its bbox
  corners, so `fillet(triangular prism, [], 1)` returned a RoundedBox holding
  twice the prism's material. The screen now rebuilds the candidate and
  requires the exact symmetric difference to vanish; rectilinear right prisms
  get the new exact answer (below), everything else refuses by name.
* **Shelling a two-component prism solid hollowed one component** and returned
  1488 where the true answer is 976. The cap walk now requires that its loop
  consume every boundary edge; the case refuses.
* **A frustum's bbox reached to the apex.** The apex skip only fired when the
  rims sat in two loops; `from_cone`/`from_revolve` put both rims in one, so
  every frustum reported its box out to the phantom apex — `cone(6,2,10)`
  measured 15 mm tall for a 10 mm solid. Sound as a bound (which is why no
  invariant caught it), 50% loose on the one shape whose point is the taper.
  `bbox`/`measure` numbers tighten on every frustum body.

## Behavior: the empty solid is an answer, not a failure

`cut(a, a)`, cut by a superset, and a disjoint intersect legitimately
annihilate the operand. The seam used to treat that three wrong ways:
`mass_props` refused, `validate` reported a violation, and `measure`/`bbox`
crashed outright. Now:

* `mass_props` reports **volume 0.0** with NaN centroid fields and
  `empty=True` — the empty set has no centroid, and none is fabricated.
* `measure` reports zero volume and zero extents.
* `validate` is ok for the empty solid *only*; a degenerate nonempty
  zero-volume solid still fails.
* `bbox` refuses structurally — the empty set has no location, and inventing
  coordinates would be a wrong number.

## Behavior: structured refusals on Body inputs

`measure()`, `validate()` and `tessellate()` on a canonical `Body` the kernel
cannot answer (e.g. a napkin ring rotated 90° about x, whose zone rims are no
longer z-perpendicular) used to let the refusal escape as a raw `ValueError` —
indistinguishable from a bug. All three now raise `KernelError`, as
`mass_props` already did. If you catch errors around these calls, catch
`KernelError`. `validate()` refuses rather than reporting when the volume
leaves the exact field: neither `ok` nor a violation is an honest answer to a
question the kernel cannot decide.

## New capability: 327 → 339

Every closed cell is pinned against a hand-derived closed form verified by an
independent oracle (Monte-Carlo membership, quadrature, or both) before
construction. The twelve, in landing order:

* **cone × shell** — the mitred inward offset of a slanted lathe profile,
  exact in ℚ[√d]: π(2192 + 960√29)/75 on the probe. The old vertex-normal-sum
  rule would have left a 0.63 mm wall where 1 mm was asked; its refusal was
  load-bearing, and the replacement is the actual 2×2 mitre solve.
* **cone × chamfer(all)** — one slant costs exactly one radical, so the
  chamfered profile stays in ℚ[√29]: π(520/3 − 110√29/87). Two slants with
  different square-free parts refuse by name (biquadratic).
* **planar prism × fillet(all)** — new `FilletedPrism`: fillet(all) on any
  rectilinear right prism, exact in ℚ[π]. Reentrant corners take inside
  fillets meeting the cap bands in quarter tori — the probe's L-profile is
  3752 + 178π/3 + π²/2. No canonical Body yet, so tessellate/STEP refuse
  honestly there.
* **shelled box × fillet(all)** — the cavity's edges are concave, so blends
  add material and the cavity becomes exactly the rounded box of its own
  dimensions: 3856 + 12π, a full 52-face canonical Body that meshes and
  exports STEP.
* **counterbore × cut box** and **bored boss × cut box** — the revived #123
  straddling-bore machinery: a box tool straddling a bore, exact on the
  canonical Body (8992 − 74π and 2682 + 737π/8). The odd-twelfth family (a
  wall crossing at 60°) computes in ℚ[√3][π] and, since #137, meshes too.
* **sphere × cut cylinder** — the probe's tool is a *blind* coaxial bore, not
  a napkin ring (the bore stops inside the material). New `SphereBlindBore`:
  three faces — the sphere minus one polar cap, the bore wall, and the tool's
  flat disk floor — π(144 + 70√35/3) = 886.0606404251233. Off-axis, band-edge
  floors and bottom entry still refuse; each is a different topology.
* **drilled (blind) × shell**, **counterbore × shell** — torus-aware erosion:
  a bore's floor rim erodes to a quarter torus, giving π² terms
  (2728 + (107/3)π + (3/2)π² and 2728 + (107/3)π + 2π² on the probes).
  Regimes that clip the torus (floor in (t, 2t], shoulder step ≤ t, wall
  under 2t) refuse by name, as finished answers.
* **shelled box × shell** — the void is the inset box minus the cavity
  dilated by t, which is exactly a RoundedBox: 3704 + (148/3)π.
* **bored boss × shell** — the composite bossed-plate erosion plus bore
  collar and floor torus: 1916 + 47π + (5/2)π².
* **chamfered box × shell** — a convex solid's erosion is its own half-spaces
  inset; the chamfer planes move t√2 and the void is a chamfered box with
  irrational depth d − (2 − √2)t, inside ℚ[√2]: 1952 − 12√2.

Not a matrix cell but new: a sphere cut by a coaxial *through*-bore returns an
exact napkin ring, (4/3)π(R² − r²)^(3/2) in ℚ[√d][π] — the first real user of
the widened field. Off-axis refuses (elliptic integrals leave every algebraic
extension).

Underneath all of it, in forge: `surdrev` (the Green contour term for
line-and-arc revolved profiles, proven against closed forms before any solid
used it), the widened `F()`, the new `NapkinRing`/`SphereBlindBore`/
`FilletedPrism` representations, and lathe torus faces now carrying their rims
as boundary loops (#130) — which is what let the answer audit drop its blanket
exemption for torus bodies.

## Permanent boundary entries: 2 → 5

Three cells moved from "gap" to "outside any exact field, permanently". Under
ADR-0019 the refusal is the finished answer; these are proofs, not backlog:

* **cone × fillet(all)** — a fillet arc contributes its turn angle linearly to
  ∮r²dz; this cone's rim turns through π − arctan(5/2), and arctan(5/2) is
  transcendental (Lindemann). By Niven only 90° and 45°/135° lathe corners
  have a turn in ℚ·π at all.
* **loft × fillet(all)** — the probe loft's dihedrals give
  arccos(1/√37)/π, transcendental by Gelfond–Schneider.
* **cone × cut box** — the tool straddles the slant wall, so the crossing
  angle varies with z and is integrated: the antiderivative emits ln(1+√2),
  independent of π over the algebraics (Baker 1966). Removed volume
  40 − (20/3)√2 − (5/3)π − (20/3)ln(1+√2), verified three independent ways.

They join sphere × cut box (arcsin) and chamfered box × chamfer(all), marked
in 0.9.6.

## Fixed: meshes that were silently wrong

* A napkin ring meshed as a **24-gon at every deflection** — the longitude
  count came from its rims (r=1), not the bulge it spans (r=6) — watertight,
  refining, and 1.5% short on volume. Latitude was also sampled uniformly in
  z against a budget set in polar angle. Both fixed; the deflection contract
  now measurably holds (worst facet-centroid error 1.7× tolerance before,
  0.87× after; mesh volume converges 0.0270 → 0.00056 relative).
* A fractional band height was truncated through `int()`: sphere R=3/2 bored
  at r=1 was **1.6% light**, silently. Fractions route through `sqrt_rational`
  now; integer bands keep their representation bit for bit.
* Chamfering a shelled box meshed with 4 bad edges at the cavity corners with
  `validate().ok` true throughout (#131): the ear clipper ate
  exactly-collinear T-junction seam vertices arriving ~1e-15 off the line.
  A noise-scaled epsilon fixes the collinearity decisions (meshing — floats
  are legal there, ADR-0019).
* The odd-twelfth family built exactly but refused to mesh (#137). The axis
  grid now runs at 12·2^d when a twelfth trim is present; `export_stl` of a
  straddling-bore body writes a real artifact.
* The STEP writer's whole-sphere branch ignored a sphere face's loops, so a
  trimmed zone would have shipped as a complete sphere. It refuses trimmed
  spherical faces by name.

## The audit, widened again

The answer audit now runs on the drilled-cut path (the one constructive path
that still skipped it — see W6 above), checks the **mesh** for watertightness
on every constructive op (coarse, 1.9 ms average; a right number behind a torn
STL is still a wrong answer), no longer exempts torus bodies from edge
pairing, and asks exact types for `.sign()` directly — the rich-comparison
route swallowed a coercion `TypeError` into `NotImplemented`, which had
disarmed the net exactly when the number field misbehaved.

## Python 3.10 was broken

`f"{x:g}"` on a `Fraction` raises on 3.10/3.11 (`Fraction.__format__` gained
format-spec support in 3.12), so every weldment call crashed on the oldest
Python we declare. 275 display-only sites across 20 files now `float()` first,
and an invariant lint fails on any new unwrapped spec. Found because the
null-kernel CI job started running again: both halves of CI had been silently
red — the "real geometry" job had installed no kernel since ADR-0020, and the
null-kernel job aborted on collection. Both are real now (the base suite runs
with no kernel installed, as the constitution claims).

## Known limits

One capability gap remains: chamfered box × fillet(all), an honest refusal.
Five cells sit permanently at the exact-field boundary, listed above. The
differential oracle still resolves errors down to ~0.2%; below that is a
stated blind spot, not a guarantee.
