# 0.9.8 — the freeform release

Six packages: `gitcad`, `gitcad-core`, `gitcad-mech`, `gitcad-ecad`,
`forgekernel`, `forgekernel_rs`.

The headline: **booleans over freeform NURBS solids** (K7). Two lofted solids
in, one audited shell out, with the volume reported as a certified interval —
a bracket proven to contain the true value — never a bare float.

## New

* `k.boolean` on lofted/patch solids: intersection, union, cut via certified
  surface-surface intersection, exact trim-loop stitching in both parameter
  domains (including open branches), exact-ℚ face partitions, certified ray
  classification, and a three-oracle shell audit (edge pairing, Σ-flux
  orientation, volume positivity — interval-aware).
* `mass_props` gains a provenance field: `exact` or `certified ± e`. The two
  tiers can never be confused.
* Zero silently dropped SSI cells: every subdivision cell resolves to a
  certified point, is proven empty, or the operation refuses by name.
* Direct editing (`move_face` / `offset_face` / `delete_face` + heal) recorded
  as replayable intent; draft with parting lines; the blend family's exact
  members; imports that audit a lying `CLOSED_SHELL` at the border.
* The viewer tessellates freeform boolean results certified-safe (the SSI
  strip renders as explicit gaps, never faked geometry).

## Honest limits

Freeform volume brackets are O(2^-depth) wide (the flagship reports ±1.69 at
depth 4); tangent contacts, operand corners, and mixed loft×planar booleans
refuse by name. A soundness upgrade to SSI closure classification awaits
sign-off on `k7/closure-signoff` and is not in this release.

Kernel floors are raised to `forgekernel>=0.9.8` — 0.9.8 code imports modules
absent from earlier wheels.
