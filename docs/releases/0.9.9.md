# 0.9.9 — the field release

Six packages. Driven by the first real field bug reports, and named for them.

## The viewer stays up

The GUI is now ONE detached server per project. It outlives the agent session
(kill the agent; the page keeps serving and live-reloading), opens the browser
proactively, always states its URL, reuses across sessions, and stops only on
an explicit `viewer_stop`. The default view is the top assembly; individual
parts are in-page sub-views (parts navigator + `#part=` deep links) — never a
second server, never one port per part. The MCP instructions now teach agents
this contract.

## Imports that cannot lie

Freeform STEP closure is certified, never sampled: cross-face agreement is a
polynomial identity in ℚ, and a shell that does not close refuses with its gap
in millimetres — down to a 1e-9 crack ("2e-09 mm open perimeter"). Heal can
repair vertex tears but provably cannot paper over a surface crack.

## Fixes

* Union of coplanar-wall lofts crashed raw on 0.9.8; it now refuses by name.
* `patch_flux` was silently wrong on B-spline surfaces with interior knots.
* The planar STEP importer silently chorded curved edges; it now refuses.
* The STEP tokenizer no longer loses entities containing quoted semicolons.
* Exact SSI closure classification and branch-island splitting (signed off).

## Drawings grow up

Every drawing renders on a standard sheet: ISO 5457 A4–A0 and ANSI Y14.1 A–E
frames with centring marks and grid references, ISO 7200 title block, standard
scale series, correct projection symbol — and the title block's author, date
and revision table derive from the part file's git history. Fields are blank
rather than invented outside a repo. Note: "A4" is now portrait, per ISO.

Kernel floors raised to `forgekernel>=0.9.9`.
